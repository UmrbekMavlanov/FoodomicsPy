# FoodomicsPy**FoodomicsPy** is an open-source Python package for foodomics data analysis## Features- Read Bruker OPUS and HDF5 datasets- Spectral preprocessing (SNV, mean centering, autoscaling, Savitzky–Golay)- NMR spectral alignment- Partial least-squares (PLS) regression with cross-validation- Interactive FTIR and NMR visualization- Publication-ready plotting utilities## Installation```bashpip install foodomicspy```Or install the latest development version:```bashgit clone https://github.com/UmrbekMavlanov/FoodomicsPy.gitcd FoodomicsPypip install .```## Quick example```pythonimport foodomicspy as f# Read spectradf = f.io.read_hdf("spectra.h5")# Preprocessdf = f.preprocessing.snv(df)# Perform PLSresult = f.chemometrics.perform_pls(    X=df,    y=y,)# Plot resultsf.plotting.plot_pls(result)```## LicenseReleased under the MIT License.
